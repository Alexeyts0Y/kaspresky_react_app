# kaspresky_react_app
## Тестовое задание
## 📖 Описание проекта:
Приложение для управления сотрудниками и группами (отделами). Проект разработан на React с фокусом на масштабируемую архитектуру и производительность обработки данных.

### 💼 Описание бизнес-логики
- Приложение эмулирует работу корпоративной директории.
- Сущности: User (Сотрудник) и Group (Отдел/Группа).
- Сотрудник может принадлежать к одной из групп или не иметь группы вовсе (например, стажер или внештатный сотрудник).
- API: Данные загружаются асинхронно, имитируя работу с реальным backend-сервером (mock API).
- Пользователи (Users Page): Доступен просмотр списка в виде таблицы. Реализован поиск и сортировка по полям. Добавлена возможность создания нового сотрудника и удаления существующего.
- Группы (Groups Page): Визуализация существующих отделов.

### ⚡ Оптимизация производительности
- Особое внимание уделено странице со списком пользователей:
- Debounce поиска: Ввод в строку поиска обернут в кастомный хук useDebounce (задержка 300мс). Это предотвращает перерисовку таблицы и "тормоза" при быстром наборе текста.
- Мемоизация (useMemo): Сортировка и фильтрация вынесены в useMemo. Тяжелые вычисления массивов происходят только при изменении исходных данных, строки поиска или направления сортировки, избавляя React от лишней работы при ререндере других частей UI.

## 🧠 Выводы о проектировании UI вручную vs LLM
При проектировании UI вручную имеется полный контроль над архитектурой компонентов, но само проектирование занимает значительно больше времени.

Проектирование с использованием LLM позволяет очень быстро получить mvp, причем прилично выглядящий. А если еще и хороший промпт, то спроектированное получается хорошо масштабируемым и без хардкода. К недостаткам как раз можно отнести то, что если промпт недостаточно подробный, то результат будет не самым удобным для его использования в будушем.

## 🚀 Запуск проекта
1. Откройте терминал в какой-нибудь папке и склонируйте туда репозиторий:
```
git clone https://github.com/Alexeyts0Y/kaspresky_react_app
```
2. Перейдите в директорию проекта:
```
сd kaspersky_react_app
```
3. Установите зависимости
```
npm install
```
4. Запустите приложение в режиме для разработки
```
npm run dev
```

Приложение будет доступно по адресу:
http://localhost:5173/
